# Dữ liệu thực nghiệm

- `results/kaggle/abp_kaggle_300s_24g_scamo_v3/`: kết quả và checkpoint của thí nghiệm v3; giữ để truy vết dữ liệu gốc của các phương pháp đối chứng.
- `results/kaggle/report_scl_nsc/`: bộ kết quả ghép để phân tích trong báo cáo, kết quả SCAMO mới, checkpoint và metadata nguồn. Xem README trong thư mục đó để phân biệt tập phân tích với thí nghiệm có thể tiếp tục chạy.
- `benchmark/`: runner, notebook Kaggle, công cụ kiểm tra và trực quan hóa; xem README trong thư mục đó.

Các kết quả từ phiên khác nhau cần được nhận diện bằng metadata, giới hạn chạy, phiên bản mã nguồn và nguồn dữ liệu; không tự coi là một thí nghiệm duy nhất.
